# AfriConnect Summit 2026

**Auteur :** Abdourahmane Ndiathie  
**Classe :** L1 DSBD — ISI  
**Examen :** Technologie Web — Robert DIASSÉ

## Description
Site vitrine d'une conférence tech fictive panafricaine réunissant développeurs, entrepreneurs et investisseurs du continent africain.

## Technologies utilisées
- HTML5 sémantique
- CSS3 (Flexbox, Grid, variables CSS, animations)
- JavaScript Vanilla
- Git & GitHub

## Fonctionnalités JavaScript
- Dark Mode avec persistance localStorage
- Navbar dynamique au scroll
- Menu hamburger mobile
- Compte à rebours en temps réel
- Compteurs animés avec IntersectionObserver
- Animations fade-in au scroll
- Onglets programme (3 jours)
- Filtrage dynamique des intervenants
- Validation complète du formulaire de contact
- Bouton retour en haut
- Année dynamique dans le footer

## Pages
- `index.html` — Accueil
- `programme.html` — Programme
- `intervenants.html` — Intervenants
- `contact.html` — Inscription & Contact
